# Advent of Code Solutions

You can find my list of solutions under `src/solutions`.

## Philosophy

I like to solve the questions by myself initially so they run in a decent amount of time (it should not take a minute) by brute force or any improved method. I will aim for simpler solutions that relate to the input data rather than fully working solutions. After I complete a day, I may look at other solutions and make small changes. If I am stuck, (2025, day 9 and 10), I may look at hints and implement the code myself.
